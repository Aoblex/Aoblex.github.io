# Aoblex

Personal academic website, powered by [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme.

- **Live site:** https://aoblex.github.io
- **Theme:** [al-folio](https://github.com/alshedivat/al-folio)

## Local development

```bash
bundle install
pip install jupyter   # if using Jupyter notebooks
bundle exec jekyll serve --livereload --port 4000
```
## 📝 Draft posts

If you want to preview draft posts (unpublished posts) locally, run Jekyll with the `--drafts` option:

```bash
bundle exec jekyll serve --drafts --livereload --port 4000
```

Site runs at http://localhost:4000.
